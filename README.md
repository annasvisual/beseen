# Anna Kovtun — Paid Ads website

## Publish
Upload index.html, styles.css, script.js and the assets/ folder to the root of your website or existing GitHub Pages repository, replacing the previous files. Keep the folder structure unchanged. No installation or build is required.

## Edit
- index.html: page text, contact details and image references.
- styles.css: page styling and responsive layout. Some original styles remain in index.html.
- script.js: contact copy buttons and current year.
- assets/: ad creatives, portrait and favicon.

This package includes the final Paid Media Management, campaign statistics, Proven Experience, Selected Ads and About sections. Product Work has been removed.

The original Google Analytics tag is retained.
